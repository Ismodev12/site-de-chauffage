Panel admin non activé

Pour activer l’administration, ajoutez la variable d’environnement ADMIN_PASSWORD (votre mot de passe) dans Vercel → Settings → Environment Variables, en cochant Production, puis redéployez le site (Deployments → ⋯ → Redeploy).

Diagnostic (ce que le site détecte actuellement)

  • ❌ ADMIN_PASSWORD (mot de passe admin) : absent
  • ❌ Base de données Upstash : absent

Environnement : local. Si une variable apparaît absente alors que vous l’avez ajoutée, vérifiez son nom exact et la case « Production », puis redéployez.
